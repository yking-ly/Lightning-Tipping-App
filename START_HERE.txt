🆘 TROUBLESHOOTING:

Problem: Backend won't start
Solution: Check Python version, activate venv, install requirements

Problem: Frontend errors
Solution: Delete node_modules, run npm install again

Problem: LNbits API errors
Solution: Verify API keys in .env, check internet connection

Problem: Database locked
Solution: Close all terminals, delete backend/tipping_app.db

Full troubleshooting guide in WINDOWS_SETUP.md section!
